# dsa405-project
This repository will contain all project files including raw data, cleaned data, notebooks, a cleaning log, and any other documentation relevant to the project.

## Project Focus
This project analyzes animal intake data from the Austin Animal Center.

## The Data
The data comes from Austin Animal Services and was published by the City of Austin.
/nRaw data: data/raw/austin_animal_center_intakes_raw.csv.gz
URL: https://data.austintexas.gov/api/v3/views/wter-evkm/query.json?accessType=DOWNLOAD

## How to Run
Open the notebook and run the cells from top to bottom. The notebook loads the raw data and performs the data audit and cleaning.
The project uses Python, Pandas, and NumPy.
